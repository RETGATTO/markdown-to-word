Convertitore locale nel browser

Markdown → Word

Converte un file .md in un documento Word .docx. Le immagini referenziate nel Markdown possono essere incorporate nel Word.

Opzione 1 — solo file Markdown

Per documenti senza immagini locali. Funziona anche con immagini via URL, se il sito remoto consente il download dal browser.

Opzione 2 — cartella progetto

Consigliata se il Markdown contiene immagini locali, per esempio ![img](images/foto.png). Seleziona la cartella che contiene il file `.md` e le immagini.

Se nella cartella ci sono più file Markdown, scegli quale convertire:
Nessun file selezionato.
🖼️
Immagini locali: per incorporarle nel file Word, usa l'opzione Seleziona cartella, così la pagina può leggere sia il file Markdown sia i file immagine referenziati.
🔒
Privacy: il contenuto del file viene elaborato nel browser. Il documento non viene inviato a un nostro server.
✓
Supporta: titoli, paragrafi, grassetto, corsivo, barrato, link, elenchi, citazioni, tabelle, blocchi di codice e immagini PNG/JPG/GIF/BMP/WEBP referenziate nel Markdown.
⚠️
Nota: per immagini remote via URL, il sito sorgente deve consentire il download dal browser; altrimenti il documento Word verrà generato senza quell'immagine e con un avviso.
Nessuna installazione richiesta. Richiede una connessione Internet per caricare le librerie JavaScript della pagina.
